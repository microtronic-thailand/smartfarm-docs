# คู่มือการพัฒนาแอปมือถือ (Mobile Development Guide) 📱

แพลตฟอร์ม Smart Farm ของเรามาพร้อมกับกลยุทธ์แอปมือถือ 2 ระดับ เพื่อตอบโจทย์ผู้ใช้งานที่หลากหลาย

---

## 🏛️ กลยุทธ์แอปมือถือ 2 ระดับ (Two-Tier Strategy)

### 1. Smart Farm Basic (ทั่วไป)
- **เทคโนโลยี**: React Native + Expo
- **เป้าหมาย**: ผู้ใช้งานทั่วไป, เกษตรกรรายย่อย
- **จุดเด่น**: ขนาดแอปเล็ก, โหลดเร็ว, ใช้งานง่าย, ครอบคลุมฟีเจอร์พื้นฐาน (ดูค่าเซนเซอร์, สั่งปิด-เปิดน้ำ)

### 2. Smart Farm Premium (พรีเมียม)
- **เทคโนโลยี**: Flutter
- **เป้าหมาย**: ผู้ใช้งานระดับองค์กร, ฟาร์มขนาดใหญ่, สมาชิกพรีเมียม
- **จุดเด่น**: UI/UX ระดับไฮเอนด์, กราฟเชิงลึก, ระบบวิเคราะห์ด้วย AI, แอนิเมชันที่ลื่นไหล, รองรับการจัดการหลายฟาร์มพร้อมกัน

---

## 🛠️ โครงสร้างโปรเจกต์ (Project Structure)

### ข้อมูลร่วม (Shared Logic)
ทั้งสองแอปจะเชื่อมต่อกับระบบหลังบ้านผ่าน:
- **Supabase SDK**: สำหรับจัดการ User Auth และ Database
- **MQTT (over WebSockets)**: สำหรับการรับข้อมูล Real-time Telemetry

### การจัดการธีม (Theming)
แอปจะดึงค่าคอนฟิกธีมจากบัญชีผู้ใช้ เพื่อให้สีสันและลุคตรงกับหน้าเว็บ Dashboard (Nature, Cyberpunk, Midnight)

---

## 🚀 ขั้นตอนการเริ่มพัฒนา

### สำหรับทีม React Native (Basic)
1. ติดตั้ง dependencies: `npm install`
2. เริ่มต้น development server: `npx expo start`
3. ไฟล์หลักอยู่ที่ `App.js` และหน้าจอต่างๆ อยู่ใน `src/screens/`

### สำหรับทีม Flutter (Premium)
1. ติดตั้ง dependencies: `flutter pub get`
2. รันแอป: `flutter run`
3. ไฟล์หลักอยู่ที่ `lib/main.dart` และหน้าจอต่างๆ อยู่ใน `lib/screens/`

| หน้าจอ | คำอธิบาย |
| :--- | :--- |

## 📡 ระบบการเชื่อมต่อ (Connectivity)

### 1. Real-time Telemetry (MQTT)
ใช้โปรโตคอล MQTT สำหรับการรับส่งข้อมูลแบบทันที:
- **Client ID**: กำหนดตาม Unique ID ของผู้ใช้
- **Topics**: ติดตาม `sf/+/telemetry` สำหรับข้อมูลเซนเซอร์ และ `sf/+/cmd` สำหรับคำสั่ง
- **Security**: เชื่อมต่อผ่าน TLS/SSL ในระบบ Cloud และ Port 1883 ใน Local Hub

### 2. Database Sync (Supabase)
ใช้ Supabase SDK ในการจัดการข้อมูลที่ต้องการความคงทน:
- ข้อมูลโปรไฟล์ผู้ใช้
- รายการอุปกรณ์ (Device List)
- กฎการทำงานอัตโนมัติ (Automation Rules)
- ข้อมูลประวัติเซนเซอร์ย้อนหลัง

---

## 🔧 การจัดการอุปกรณ์ (Device Provisioning)
ในแอปมือถือทั้งสองเวอร์ชัน ผู้ใช้สามารถ:
1. **Add Device**: เพิ่มอุปกรณ์ใหม่ผ่านการระบุชื่อหรือสแกน QR Code (อนาคต)
2. **Device List**: ดูสถานะ Online/Offline ของบอร์ดแต่ละบอร์ด
3. **Delete Device**: ลบอุปกรณ์ที่ไม่ต้องการออกจากการจัดการ
