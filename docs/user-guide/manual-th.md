# คู่มือการใช้งานแพลตฟอร์ม (User Manual)

ยินดีต้อนรับสู่ระบบบริหารจัดการฟาร์มอัจฉริยะ คู่มือนี้จะช่วยให้คุณเข้าใจการใช้งานส่วนต่างๆ ของ Dashboard เพื่อให้คุณดูแลฟาร์มได้อย่างมีประสิทธิภาพสูงสุด

---

## 🧭 การนำทางหลัก (Main Navigation)

แถบเมนูด้านซ้ายคือหัวใจหลักในการสลับการทำงาน:
- **ภาพรวม (Overview)**: สรุปสถานะฟาร์มทั้งหมดในหน้าเดียว
- **มอนิเตอร์สด (Live Monitor)**: ดูค่าเซนเซอร์แบบวินาทีต่อวินาทีและกราฟย้อนหลัง
- **บ้านอัจฉริยะ (Smart Home)**: ควบคุมอุปกรณ์ภายในบ้านหรือโรงเรือนเพาะปลูก
- **ตลาดซื้อขาย (Marketplace)**: เพิ่มความสามารถใหม่ๆ ให้ระบบด้วยเทมเพลตและส่วนขยาย
- **อุปกรณ์ของฉัน (My Devices)**: จัดการการเชื่อมต่อและตั้งค่าบอร์ดคอนโทรลเลอร์

---

## 📊 การอ่านค่า Dashboard (Understanding Dashboard)

เราใช้สัญลักษณ์สากลเพื่อให้คุณเข้าใจสถานะได้ทันทีแม้ไม่ได้อ่านข้อความ:

### 1. การ์ดสถานะเซนเซอร์ (Sensor Cards)
- 🌡️ **อุณหภูมิ (Temperature)**: อากาศร้อนหรือเย็นเกินไป (หน่วยเป็น °C)
- 💧 **ความชื้นสัมพัทธ์ (Humidity)**: ปริมาณไอน้ำในอากาศ (หน่วยเป็น %)
- 🌱 **ความชื้นดิน (Soil Moisture)**: ดินแห้งหรือแฉะ (หน่วยเป็น %)
- ☀️ **ความเข้มแสง (Light Level)**: พืชได้รับแสงเพียงพอหรือไม่ (หน่วยเป็น Lux)

> **เคล็ดลับ**: หากตัวเลขเป็นสีแดง หมายถึงค่าอยู่นอกช่วงวิกฤตที่ตั้งไว้

### 2. กราฟแนวโน้ม (Trend Charts)
กราฟจะแสดงการเปลี่ยนแปลงย้อนหลัง 24 ชั่วโมง ช่วยให้คุณวิเคราะห์ได้ว่าช่วงไหนของวันที่พืชมีความเครียดสูงสุด

---

## ⚡ การสั่งงานด่วน (Quick Actions)

คุณสามารถควบคุมอุปกรณ์หน้างานได้โดยตรงจากหน้าจอ:
- **ปุ่มรูปหยดน้ำ (Irrigation)**: กดเพื่อเปิด/ปิดระบบรดน้ำ
- **ปุ่มรูปพระอาทิตย์ (Lights)**: กดเพื่อเปิด/ปิดไฟปลูกพืช

---

## 🏠 ระบบ Hybrid (อินเทอร์เน็ตล่มทำอย่างไร?)

แพลตฟอร์มของเราถูกออกแบบให้ทำงานได้แม้ไม่มีอินเทอร์เน็ต:
1. **โหมดออนไลน์**: ข้อมูลทิ้งหมดจะถูกเก็บไว้บนระบบ Cloud คุณสามารถดูได้จากทุกที่
2. **โหมดออฟไลน์ (Hybrid)**: หากอินเทอร์เน็ตขาดหาย บอร์ดคอนโทรลเลอร์จะสลับไปทำงานร่วมกับ **Edge Hub** ในฟาร์มของคุณโดยอัตโนมัติ เพื่อรันระบบรดน้ำตามกำหนดการเดิม

---

## 🆘 การแก้ไขปัญหาเบื้องต้น

- **ไฟสถานะสีแดง**: อุปกรณ์ขาดการเชื่อมต่อ ให้ตรวจสอบการเสียบปลั๊กและสัญญาณ WiFi
- **ค่าเซนเซอร์ไม่ขยับ**: ตรวจสอบการเชื่อมต่อสายเซนเซอร์ที่ตัวบอร์ด
- **หน้าจอไม่แสดงผล**: ลองกดปุ่ม **Refresh** (รูปลูกศรวงกลม) ที่มุมขวาบน
