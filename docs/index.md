# Welcome to Smart Farm IoT Platform

Welcome to the official documentation for the **Smart Farm IoT Platform**. This platform is designed to help farmers and IoT enthusiasts monitor, control, and optimize their agricultural operations using modern technology.

## Core Features

- **Real-time Monitoring**: Track temperature, humidity, soil moisture, and more in real-time.
- **Smart Control**: Automate irrigation, lighting, and climate control.
- **AI Analytics**: Use machine learning to predict crop health and yields.
- **Cross-Platform**: Access your farm data from anywhere via web and mobile.
- **Scalable Hardware**: Support for ESP32, ESP8266, and STM32 microcontrollers.

## How to use this documentation

- If you are new, start with the **[Introduction](introduction.md)**.
- For hardware setup, check our **[Hardware Support](hardware/index.md)** section.
- Developers can refer to the **[API Reference](api/index.md)**.
- To connect your devices, see the **[Arduino Library](library/arduino.md)** guide.
