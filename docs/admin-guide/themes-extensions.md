# คู่มือการสร้างธีมและส่วนขยาย (Themes & Extensions Guide) 🎨🔌

แพลตฟอร์มของเราถูกออกแบบมาให้ขยายขีดความสามารถได้ง่ายผ่านระบบ Marketplace เพื่อสร้างรายได้เพิ่มเติมและปรับแต่งประสบการณ์ให้เข้ากับความต้องการเฉพาะของลูกค้า

---

## 🎨 1. การสร้างธีมใหม่ (Creating Themes)

ระบบธีมของเราใช้ **CSS Variables** เป็นหลัก ทำให้คุณสามารถเปลี่ยนลุคของ Dashboard ได้ทั้งหมดโดยไม่ต้องแก้โค้ดหลัก

### ขั้นตอนการสร้าง:
1.  **กำหนดตัวแปรสี**: สร้างชุดตัวแปร CSS ในไฟล์ `globals.css` ภายใต้ attribute `data-theme` ใหม่
2.  **ตัวอย่างโค้ด (CSS)**:
```css
[data-theme='my-new-theme'] {
  --bg-primary: #0f172a;       /* พื้นหลังหลัก */
  --bg-secondary: #1e293b;     /* พื้นหลังรอง */
  --accent-primary: #f59e0b;    /* สีเด่น (ปุ่ม/ไอคอน) */
  --accent-secondary: #d97706;  /* สีเด่นรอง */
  --foreground: #f8fafc;       /* สีตัวอักษร */
  --glow-color: rgba(245, 158, 11, 0.4); /* สีแสงเรือง */
}
```
3.  **ลงทะเบียนธีม**: เพิ่มชื่อธีมใหม่ลงใน `ThemeContext.tsx` เพื่อให้ปรากฏในเมนูเลือกธีม

## 🔌 2. การพัฒนาส่วนขยาย (Developing Extensions)

ส่วนขยาย (Extensions/Addons) คือคอมโพเนนต์เสริมที่ช่วยเพิ่มฟีเจอร์ใหม่ๆ เช่น ระบบวิเคราะห์ด้วย AI หรือกราฟสถิติแบบพิเศษ

### ประเภทของส่วนขยาย:
- **UI Widgets**: บล็อกแสดงผลข้อมูลแบบพิเศษ (เช่น แผนที่ความร้อนของคาร์บอน)
- **Service Addons**: ระบบแจ้งเตือนผ่านช่องทางใหม่ๆ (เช่น โทรศัพท์แจ้งเหตุอัตโนมัติ)
- **AI Extensions**: การเชื่อมต่อกับโมเดลวิเคราะห์โรคพืชหรือพยากรณ์ผลผลิต

### ขั้นตอนการสร้าง Extension (UI Widget):
1.  **สร้างคอมโพเนนต์**: สร้างไฟล์ React ใหม่ใน `components/marketplace/extensions/`
2.  **การเชื่อมต่อข้อมูล**: ใช้ `useSupabase` หรือ `useMQTT` เพื่อดึงข้อมูลมาแสดงผล
3.  **ตัวอย่างโครงสร้าง**:
```tsx
export default function WeatherPro() {
  return (
    <div className="glass-card p-6 rounded-3xl border border-blue-500/30">
       <h3 className="text-xl font-bold">Weather Forecast Pro</h3>
       {/* ใส่ตรรกะการดึงข้อมูลและแสดงผลที่นี่ */}
    </div>
  );
}
```

## 📈 3. แนวทางการออกแบบ (Design Guidelines)

เพื่อให้ธีมและส่วนขยายของคุณดูพรีเมียมและเป็นมืออาชีพ:
- **Glassmorphism**: ใช้ความโปร่งใส (`backdrop-blur`) และเส้นขอบบางๆ เพื่อความล้ำสมัย
- **Consistency**: ใช้ไอคอนจากชุด `lucide-react` เพื่อความสม่ำเสมอ
- **Performance**: ส่วนขยายไม่ควรโหลดทรัพยากรมากเกินไปจนทำให้ Dashboard ช้าลง

---

## 💰 4. การนำขึ้น Marketplace

สำหรับการขายหรือแจกจ่าย:
1.  **เตรียม Metadata**: ชื่อ, คำอธิบาย, ราคา, และรูปตัวอย่าง (Thumbnail)
2.  **Versioning**: ระบุเวอร์ชันที่รองรับเพื่อไม่ให้เกิดข้อผิดพลาดเมื่อระบบหลักอัปเดต
3.  **Preview**: ทดสอบการใช้งานร่วมกับธีมหลักทั้งหมดว่ายังอ่านง่ายและสวยงามหรือไม่

## 📥 5. การนำสินค้าเข้า Marketplace (Importing to Marketplace)

ผู้ดูแลระบบสามารถนำธีมหรือส่วนขยายใหม่เข้าสู่ระบบได้ผ่านช่องทางดังนี้:

### 1. วิธีการผ่าน Database (Manual Import)
ทำการเพิ่มข้อมูลลงในตาราง `marketplace_items` ในฐานข้อมูล Supabase:
```sql
INSERT INTO public.marketplace_items (name, description, type, price, author, image_url)
VALUES (
  'Neon Cyberpunk', 
  'ธีมย้อนยุคอนาคต สีชมพู-ม่วง สำหรับสายไฮเทค', 
  'template', 
  9.99, 
  'Grids Micro Team',
  'https://example.com/thumb.jpg'
);
```

### 2. โครงสร้างข้อมูลที่สำคัญ
- **`type`**: ต้องระบุเป็น 'template' หรือ 'extension' เท่านั้น
- **`metadata`**: ใช้เก็บค่าคอนฟิกพิเศษ (เช่น รายชื่อไฟล์ JS/CSS ที่ต้องโหลดเพิ่ม)
- **`image_url`**: ลิงก์รูปภาพตัวอย่างขนาด 400x300 px (แนะนำ)

### 3. การตรวจสอบความปลอดภัย
ก่อนนำส่วนขยายขึ้นสู่สาธารณะ:
- ตรวจสอบว่าโค้ดไม่มีการส่งข้อมูลออกไปยังเซิร์ฟเวอร์ภายนอกที่ไม่ได้รับอนุญาต
- ตรวจสอบประสิทธิภาพการรัน (ไม่ทำให้ Dashboard ค้าง)
- ตรวจสอบว่ารองรับทั้งภาษาไทยและอังกฤษ
